# Example contracts, not prebuilt apps

The three manifests describe the target reference plugins. Their UI/Wasm files have not been built.
The repository URL is the intended public project, not a claim it has been published. The Feed Reader
uses a reserved example domain that must be replaced with a controlled fixture endpoint in tests and
an approved real source before release. Never publish sample manifests as working plugin releases.
The release verifier rejects missing assets and fixture identities/digests.
