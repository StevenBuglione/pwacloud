# Contributing

Read `AGENTS.md`. Run the reference tests before working on the target implementation. Link each change
to a milestone and acceptance case. Add tests with behavior changes. Explain privilege expansions.
Avoid unrelated refactors. Do not add a runtime dependency without a maintenance and license review.
Use reviewable commits and pull requests. Public CI uses synthetic credentials and fixtures only.

Production packages use strict TypeScript, Rust/WIT guests, generated contracts, and pinned lockfiles.
Contributors retain ownership of their contributions and license them under the repository's MIT license.
Do not submit third-party code or assets without a compatible license and provenance.
